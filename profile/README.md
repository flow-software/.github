## Flow Software

We build software that turns industrial data into information people can act on.

- **Timebase**: a historian and the tools around it for collecting, storing and exploring
  time series data.
- **Infohub** (formerly Flow): turns that data into KPIs, reports and dashboards.

Documentation: [docs.timebase.com](https://docs.timebase.com)

### Public repositories

| Repository | What it is |
|---|---|
| [Infohub-Grafana](https://github.com/flow-software/Infohub-Grafana) | Grafana plugins for Infohub |
| [InfoHub-Profiles](https://github.com/flow-software/InfoHub-Profiles) | Schema definitions for Infohub measure and event profiles |
| [Flow-Custom-Functions](https://github.com/flow-software/Flow-Custom-Functions) | SDK for writing custom functions |
| [Ignition-Module-Signer](https://github.com/flow-software/Ignition-Module-Signer) | Module signer for Ignition, with PKCS11 hardware key support |

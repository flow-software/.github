# Typography

## Typefaces

| Role | Typeface | Use |
|---|---|---|
| Primary | [Poppins](https://fonts.google.com/specimen/Poppins) | Brand identity, headings, marketing, hero sections |
| Secondary | [Inter](https://fonts.google.com/specimen/Inter) | UI body text, labels, inputs, data-dense screens |
| Editorial | [Playfair Display](https://fonts.google.com/specimen/Playfair+Display) | Editorial headings only: whitepapers, long-form |
| Code | [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) | Code and fixed-width values in the product UIs |

## Approved pairings

Never use all three of Poppins, Inter and Playfair Display in one layout.

- Poppins headings with Inter body: the default for product UI.
- Playfair Display headings with Inter body: editorial and marketing only.

Poppins is a heading face. Do not set body paragraphs in it.

## Type scale (product UI)

| Level | Typeface | Weight | Size | Line height | Letter spacing |
|---|---|---|---|---|---|
| Display | Poppins | SemiBold | 48px | 110% | -2% |
| H1 | Poppins | SemiBold | 36px | 115% | -2% |
| H2 | Poppins | Medium | 30px | 120% | -1% |
| H3 | Poppins | Medium | 24px | 125% | -1% |
| H4 | Poppins | Medium | 20px | 130% | 0 |
| Body | Inter | Regular | 16px | 150% | 0 |
| Body small | Inter | Regular | 14px | 150% | 0 |
| Caption | Inter | Medium | 12px | 140% | 0.5% |
| Label | Inter | SemiBold | 14px | 100% | 0.5% |

Tighten letter spacing and line height on headings; keep body text at 150% line height.

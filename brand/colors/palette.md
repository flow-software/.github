# Palette

The same values are in [tokens.json](tokens.json) and [tokens.css](tokens.css). The CSS variable
names match the ones the Timebase UI uses, so a value can be traced straight to the product.

## Core

| Name | Hex | Variable | Use |
|---|---|---|---|
| Charcoal | `#1F1F23` | `--tb-charcoal` | Dark mode background, light mode text |
| Anti-Flash White | `#F2F2F2` | `--tb-anti-flash` | Light mode background, dark mode text |
| White | `#FFFFFF` | `--tb-white` | Pure white |
| Timebase Blue | `#31AEE4` | `--tb-blue-500` | Primary interactive: buttons, links |
| Infohub Green | `#36E063` | `--tb-green-500` | Secondary call to action, success accent |
| Jungle Green | `#06624E` | `--tb-green-800` | Hover and focus for green elements |
| Logomark Blue | `#0BB6FF` | `--tb-blue-logomark` | Brand mark only, never UI |

## Secondary

| Name | Hex | Variable | Use |
|---|---|---|---|
| Control Blue | `#1B81AD` | `--tb-blue-600` | Hover and active for blue elements |
| Lucky Blue | `#4CD6F5` | `--tb-blue-300` | Informational highlights |
| Lucky Green | `#34D399` | `--tb-green-400` | Positive and connected feedback |
| Vivid Orange | `#F59E0B` | `--tb-orange-500` | Warnings |
| Coral Red | `#EF4444` | `--tb-red-500` | Alerts, failed validation, destructive actions |

## Neutrals

| Name | Hex | Variable | Use |
|---|---|---|---|
| Light Gray | `#E5E7EB` | `--tb-light-gray` | Light mode dividers, borders, outlines |
| Silver Mist | `#D1D5DB` | `--tb-silver-mist` | Dark mode secondary text |
| Iron Gray | `#374151` | `--tb-iron-gray` | Light mode secondary text, subheadings |

# Timebase logos

Empty for now. Add the official Timebase logos here as SVG masters with PNG exports beside them.

Expected variants, named `timebase-<variant>-<color>.<ext>`:

| Variant | What it is |
|---|---|
| `logo-full` | Mark and wordmark together, the default |
| `mark` | The mark alone, for small spaces |
| `wordmark` | The name alone |

Colors: `color`, `white` and `black`, so there is a version for light and dark backgrounds.

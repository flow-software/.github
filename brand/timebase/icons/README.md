# Timebase icons

| File | What it is |
|---|---|
| `timebase-icon.svg` | Master: the star in Logomark Blue `#0BB6FF`, uncropped, as shipped by the apps |
| `favicon.ico` | 16, 32, 48, 64 and 256px |
| `timebase-icon-<size>.png` | 16, 32, 180, 192 and 512px. Transparent, the mark centred with a 6% margin |

## Source

`timebase-docs/assets/brand/favicon.svg` and `favicon.ico`. The SVG is identical to the `favicon.svg`
in the Bridge, Collector, Connect and Explorer UIs. The `.ico` is identical to the one in the Historian
and Portal UIs. The 180px PNG is transparent: iOS shows transparency as black, so add a background
if the icon is used as an apple-touch-icon.

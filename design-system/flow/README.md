# Flow Software design system

Bare. This folder will hold what every Flow Software product shares, whatever its UI stack:

- Foundations taken from the brand kit: palette, type faces and scale, logo use and clear space.
- Rules that cross products: icon style, tone of voice and copy rules, accessibility minimums, how to
  review a UI against a design system.

Nothing is written yet. Put a rule here only when two or more products need it. Product specific
rules go in the product folder.

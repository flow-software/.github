# Contributing

Thanks for taking the time to help. This guide applies to every Flow Software repository that does
not have its own.

## Reporting a problem

Open an issue in the repository it concerns. Say what you did, what you expected, and what happened
instead, and include the version you were running.

Do not report security problems in an issue. See [SECURITY.md](SECURITY.md).

## Proposing a change

1. Open an issue first for anything larger than a small fix, so we can agree on the approach before
   you spend time on it.
2. Fork the repository and make your change on a branch.
3. Keep the pull request to one change, and describe what it does and why.
4. Make sure it builds and the tests pass.

A maintainer will review it. We may ask for changes before merging.

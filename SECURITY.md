# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Email [support@timebase.com](mailto:support@timebase.com) with:

- the product and version affected,
- what the problem is and how to reproduce it,
- what an attacker could do with it.

We will acknowledge your report, keep you informed while we work on a fix, and credit you when it
is released if you would like.
